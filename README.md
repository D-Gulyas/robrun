# ROB RUN – Fan-Toolkit

Sammel-Repo für alles rund um **ROB RUN**: komplett statische Webseiten, veröffentlicht über GitHub Pages.

**🌐 Live: https://d-gulyas.github.io/robrun/**

| Projekt | Live | Ordner |
|---|---|---|
| 🗺️ Interaktive Karte von Looty Bay (inkl. aller 53 Mülltonnen) | https://d-gulyas.github.io/robrun/karte/ | [`karte/`](karte/) |
| 📐 Blaupausen (Anbauraum, Polizeifunk & Radio, Schlüsselräume, Sammeltisch) | https://d-gulyas.github.io/robrun/blaupausen/ | [`blaupausen/`](blaupausen/) |

## Aufbau

```
index.html        Startseite mit Links zu allen Tools
karte/            Interaktive Karte (eigene README)
blaupausen/       Blaupausen-Viewer (eigene README)
.nojekyll         GitHub Pages liefert alle Dateien unverändert aus
```

Jedes Tool liegt in seinem eigenen Ordner und funktioniert für sich allein.
Ein neues Tool bekommt einfach einen weiteren Ordner und eine Kachel auf der Startseite (`index.html`).

## Veröffentlichen

GitHub Pages ist auf **`main` / Hauptordner** eingestellt. Änderungen committen und pushen –
nach etwa einer Minute sind sie live.

Inoffizielles Fan-Projekt, nicht mit Kefir oder ROB RUN verbunden.
